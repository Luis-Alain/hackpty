# Recovered PsyRec mobile design study

[Open the original interactive study](psyrec-mobile-design.html). [Capture storyboard](psyrec-mobile-capture.png) and [future history storyboard](psyrec-mobile-history.png) preserve the visual work supplied by Jeff. The original notes and browser checks are retained unchanged; their historical local paths are reference provenance, not application dependencies.

The original task created a standalone preview and made no application or Git changes. The capture storyboard is now the visual reference for the native mobile implementation. The existing [desktop styling](../../../apps/desktop/ui/style.css) and [desktop workspace](../../../apps/desktop/ui/index.html) are its original design authority.

Scope: connect, capture, encrypted pending/retry and matching-receipt completion map to actual native transport state. Camera frames must show the real preview. The history, on-phone inference and patient-scoped RAG concepts remain planned until separately implemented and measured; they must not appear as operational capabilities.

The original browser checks verify the standalone study only. They are not Android, clinical or release acceptance evidence. See [recovery hashes](recovery.json) for the byte-preserved source files.
